# SmartResumeAnalyzer

SmartResumeAnalyzer is a resume analysis web application that helps users upload resumes and get structured feedback on skills, job matching, and career path alignment. The project includes a React frontend and a Python/Node backend to parse resume content, identify relevant skills, and suggest job or course recommendations.

## Project Structure

- `frontend/` – React app for uploading resumes, displaying analysis results, and showing suggested improvements.
- `backend/` – Server-side code for resume parsing, skill extraction, job matching, and related logic.
- `models/` – Data assets used for matching and analysis, such as CSV job listings.
- `reports/` – Generated output or analysis summaries.
- `smart_resume_system/` – Additional resume and job matcher utilities.

## Key Features

- Resume upload and parsing
- Skill extraction and scoring
- Job matching based on resume content
- Career path and course recommendations

## Getting Started

1. Install dependencies for both `frontend` and `backend`.
2. Run the backend server.
3. Start the frontend development server.
4. Open the app in your browser and upload a resume for analysis.
